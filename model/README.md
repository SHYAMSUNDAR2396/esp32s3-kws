# Model

## `ds_cnn_int8.tflite` — PLACEHOLDER, UNTRAINED

Generated by `gen_model.py`. **The weights are randomly initialised.**

This model exists so that the *runtime infrastructure* can be measured on a
graph with the correct architecture, correct INT8 quantisation and correct
tensor shapes. Specifically, these are real measurements:

- tensor arena size actually used by TFLite Micro
- model footprint in flash
- input/output tensor shapes, scales and zero-points
- inference latency (subject to the Wokwi caveats in the top-level README)

**These are NOT measurements and cannot be derived from this model:**

- wake-word accuracy
- false-accept rate (the `< 1 / 12 h` target)
- false-reject rate
- any confidence score, threshold quality, or ROC curve

The score output is arbitrary. In practice it sits near 0.5, which is exactly
what a random 2-class softmax produces.

## Architecture

DS-CNN, after Zhang et al., *Hello Edge: Keyword Spotting on Microcontrollers*
(2017), narrowed to 32 channels to suit a 256 KB RAM budget.

```
input 1 x 25 x 40 x 1  int8          25 frames x 20 ms hop = 500 ms context
  Conv2D 32 @ (10,4) stride (2,2) + ReLU
  4x [ DepthwiseConv2D (3,3) + ReLU
       Conv2D 32 @ (1,1) + ReLU ]
  GlobalAveragePooling2D
  Dense 2 + Softmax                  {not-wake, wake}
```

6,882 parameters, 19,912 bytes as `.tflite`, ~1.70 M MACs per inference.

## Replacing it with a trained model

1. Train the same topology on your wake word (Google Speech Commands plus
   your own recordings; keep the 40-mel / 20 ms-hop front end identical to
   `main/features.cpp`, or the features the model sees at run time will not
   match the ones it was trained on).
2. Use a **representative dataset of real log-mel frames** for quantisation
   calibration, not the random tensors in `gen_model.py`.
3. Re-run `gen_model.py`'s conversion + C-array export step.
4. Re-measure the arena — a trained model with different activation ranges
   can need a different arena size.
5. Only then may accuracy or false-accept numbers be quoted, and only against
   a held-out labelled set.

## Regenerating

```
python3.12 -m venv /tmp/kws-tf
/tmp/kws-tf/bin/pip install tensorflow
/tmp/kws-tf/bin/python gen_model.py
```

TensorFlow has no wheels for Python 3.14; 3.12 works.
